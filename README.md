# Milligo site

The public pages for Milligo: About and the privacy policy. English is at the
root (`/`, `/privacy/`) and Polish under `/pl/` (`/pl/`, `/pl/privacy/`). GitHub
Pages serves them from `main`.

Plain HTML and one stylesheet, with no build step, scripts or requests to other
companies. The privacy policy promises exactly that, so keep it true. When the
policy's text changes, change both languages and update the "Last updated" date
on both pages.
